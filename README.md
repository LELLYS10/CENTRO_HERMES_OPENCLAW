# CENTRO HERMES OPENCLAW

Porta de entrada operacional do ecossistema `Hermes + OpenClaw + CredPlus`.

Comece por:
- `HOME.html`

Regras:
- `HERMES/` = memória, contexto, Google, agenda, Gmail, Drive, assistente.
- `OPENCLAW/` = agentes, dispatcher, operação CredPlus, execução estruturada.
- `CREDPLUS/` = base sólida do sistema e verdade do negócio.
- `00_MAPAS_VISUAIS_GERAIS/` = mapas HTML e ícones visuais.
- cada módulo tem um `COMANDO_CENTRAL_*.md` pequeno apontando para subpastas menores.
