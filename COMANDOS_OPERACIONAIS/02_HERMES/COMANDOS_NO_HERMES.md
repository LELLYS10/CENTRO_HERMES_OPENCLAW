# COMANDOS NO HERMES

## Papel
Hermes usa comandos como camada de:
- memoria
- interpretacao
- resumo
- contexto
- interface inteligente

## Aplicacao forte
- `/goal` para missoes do dia
- `/background` para varredura e pesquisa
- `/resume` para continuidade
- `/steer` para ajuste fino
- `/curator` para evolucao de skills
- `/model` para trocar custo e profundidade

## Exemplo
- `goal: organizar agenda e comprovantes do dia`
- `background: revisar erros do Herminho`
- `resume: auditoria da agenda`
