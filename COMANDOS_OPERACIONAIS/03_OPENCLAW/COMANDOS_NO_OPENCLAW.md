# COMANDOS NO OPENCLAW

## Papel
OpenClaw usa comandos como camada de:
- execucao
- orquestracao
- automacao
- agentes especialistas
- rotina operacional

## Aplicacao forte
- `/handoff` para receber missao do Hermes
- `/kanban` para fila e fluxo
- `/cron` para recorrencia
- `/stop` para controle de processo
- `/goal` para operacao fechada

## Exemplo
- `handoff: Hermes envia cobranca para OpenClaw`
- `cron: revisar vencidos 08h`
- `stop: interromper watcher duplicado`
