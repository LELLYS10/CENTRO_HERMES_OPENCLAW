# INDICE COMANDOS OPERACIONAIS

## Estrutura
- `00_ENTRADA_RAPIDA`: leitura curta
- `01_COMANDOS_BASE`: significado dos comandos
- `02_HERMES`: como os comandos entram no Hermes
- `03_OPENCLAW`: como os comandos entram no OpenClaw
- `04_CREDPLUS`: aplicação no sistema CredPlus
- `05_HANDOFF_E_GATEWAY`: ponte entre motores e canais
- `06_CRONS_E_ROTINAS`: recorrência e automação
- `07_GOVERNANCA_E_LIMITES`: limites, parada e aprovação
