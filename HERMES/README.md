# HERMES

## Regra oficial
A **fonte-mãe do Hermes** é a pasta:
- `Organização 2026 / Heminho`

Esta pasta `HERMES/` no centro **não substitui** a base do Heminho.
Ela existe só para:
- servir de portal
- separar Hermes de OpenClaw
- facilitar navegação
- evitar mistura com CredPlus e OpenClaw

## Use nesta ordem
1. `FONTE_MAE_HERMES.md`
2. `COMANDO_CENTRAL_HERMES.md`
3. `00_ENTRADA_RAPIDA/`
4. `03_SECOES/` somente quando precisar entrar na base viva
