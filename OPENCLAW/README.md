# OPENCLAW

## Regra oficial
A base viva do OpenClaw está ancorada nos projetos e materiais principais:
- `credplus-openclaw-sync`
- `BOBY OpenClaw`
- `Manual OpenClaw`

Esta pasta `OPENCLAW/` no centro é um portal para:
- navegação
- separação de contexto
- acesso rápido
- mapas e identidade do módulo
